# 🚐 TravelTrucks

A modern camper rental web application built with **Next.js**, **React**, and **TypeScript**.

TravelTrucks allows users to browse a camper catalog, filter vehicles by different criteria, view detailed camper information, and submit booking requests through a responsive and user-friendly interface.

---

## ✨ Features

- 🚐 Browse available campers
- 🔍 Filter campers by:
  - Location
  - Camper type
  - Engine type
  - Transmission
- 📄 View detailed camper information
- 📅 Submit booking requests with validation
- 🔄 Infinite scrolling powered by TanStack Query
- 🔔 Toast notifications for user feedback
- 📱 Fully responsive design (desktop, tablet, mobile)
- ⚡ Fast navigation with Next.js App Router
- 🌐 SEO optimization with Metadata API, Open Graph, and Twitter Cards

## 📂 Project Structure

```text

├── catalog/
│   ├── page.tsx              # Catalog page (/catalog)
│   └── [id]/
│       └── page.tsx          # Dynamic camper page (/catalog/:id)
│
├── components/               # Reusable UI components
│

│
├── types/                    # TypeScript types and interfaces
│
```

## ⚙️ Installation

```bash
git clone https://github.com/Vl-as/travel-trucks.git

cd travel-trucks

npm install

npm run dev
```

Open:

```text
http://localhost:3000
```
